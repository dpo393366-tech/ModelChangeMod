# ModelChangeMod

[최신 배포판 다운로드](https://github.com/dpo393366-tech/ModelChangeMod/releases/latest)

[지원 모델과 원본 다운로드 주소](지원모델_목록.txt) · [포함 도구 라이선스 안내](포함도구_라이선스안내.txt)

릴리스의 `ModelChangeMod-R458-install.zip`을 내려받아 전체 압축을 푼 다음, 기존과 같이 아래 버튼 중 하나를 실행합니다.

- `설치하기(고사양).bat`: 원본 모델 텍스처 품질.
- `설치하기(저사양).bat`: 지원 모델 텍스처를 최대 512px로 제한하여 메모리 사용 절감.

두 모드 모두 CG 원본 화질·30fps를 유지하며, 검증된 27개 Live CG의 반복 구간을 단축합니다.

원본 모델은 포함하지 않습니다. `지원모델_목록.txt`의 원작자 배포처에서 별도로 내려받아 비어 있는 `원본모델_넣는곳` 폴더에 넣어 주세요. `_work`, 원본 모델 압축파일, 개인 진단 기록, 서명 비밀키는 공개하지 않습니다. Git 저장소의 `.gitkeep`은 빈 폴더를 유지하기 위한 표시이며, 설치 ZIP의 원본 폴더는 비어 있습니다.

R457 이전 사용자는 이번 R458 설치 버튼을 한 번 실행해야 게임 시작 자동 업데이트 기능이 설치됩니다. 이후에는 Steam이나 게임 실행 파일로 평소처럼 실행하면 됩니다. 설치 BAT를 다시 실행해야 패치되는 방식이 아닙니다.

게임이 모드를 불러오기 전에 GitHub의 최신 정식 릴리스를 확인하고, 변경된 모드 실행 코드와 지원 파일의 추가·수정·제거를 적용합니다. 인터넷 연결이 끊기거나 다운로드가 손상되면 기존 설치로 실행합니다. 사용자 수정 CG·개인 설정·저장 파일·원본 모델·다른 모드는 보존합니다.

신규 캐릭터의 코드·CG·효과·변환 정보도 업데이트할 수 있습니다. 해당 캐릭터의 원본 모델은 자동 다운로드하지 않습니다. 원본을 별도로 받은 뒤 기존 설치 버튼을 실행하면 게임에 전달된 최신 변환 정보를 이용해 추가할 수 있습니다.

업데이트가 있는 날에는 다운로드 시간만큼 첫 시작이 길어질 수 있습니다. 초기화에 실패한 업데이트는 다음 시작 때 이전 버전으로 복원합니다. 게임 자체의 오류나 모든 미래 게임 버전과의 호환성을 보장하지는 않습니다.

개발·배포 절차는 [배포 도구 설명](release_tools/PUBLISHING.md)을 참고하세요.
