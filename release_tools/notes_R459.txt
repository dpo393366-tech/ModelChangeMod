R459 — 레미엘 돌파 날개 누락 수정

R458 패키징에서 원본 모델 제외 규칙에 날개 보조 메시까지 걸려 빠졌습니다. 이 때문에 레미엘 돌파에서 날개를 생성하지 못하는 문제를 수정했습니다.

R458 설치 사용자는 게임을 완전히 종료한 뒤 다시 실행하면 자동 업데이트됩니다. 설치 BAT 재실행이나 별도 PC 설치는 필요 없습니다. 원본 레미엘 모델은 이미 설치돼 있어야 합니다.

누락된 날개 전용 보조 메시와 이를 읽는 런타임 코드를 같은 업데이트로 전달합니다. R458의 기존 업데이트 프로그램과 호환되며, 원본 모델 압축파일·캐릭터 본체·_work는 포함하지 않습니다. 고사양·저사양 설정은 유지합니다.

처음 설치하거나 R457 이하에서 넘어오는 사용자는 ModelChangeMod-R459-install.zip 전체를 풀고 고사양·저사양 설치 버튼 중 하나를 실행하세요.

지원 모델·원본 다운로드 주소: https://github.com/dpo393366-tech/ModelChangeMod/blob/main/지원모델_목록.txt
포함 도구 라이선스 안내: https://github.com/dpo393366-tech/ModelChangeMod/blob/main/포함도구_라이선스안내.txt
두 안내 파일은 설치 ZIP과 아래 Assets에도 포함돼 있습니다.

검증: 원래 R458 배포 ZIP의 시작 DLL·내장 Python·업데이트 프로그램을 수정하지 않은 별도 시험 환경에서 R459 한 번 적용, 날개 메시·텍스처 구성, 설정·원본 보존을 확인했습니다. Unity 게임 내 렌더링은 별도 확인 범위입니다. 사용자 PC의 기존 게임 설치 파일은 직접 수정하지 않았습니다.
